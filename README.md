# Purpose

This repository contains a translation for some Call of Cthulhu modules for the Foundry
The translation exists only to Russian language
It was almost fully done with the Depp Seek. Some of the values were verified, but there are a lot of inconsistencies in the translation
If you stumble upon this repository and want to use for yourself, feel free to do so, but don't excpect this module to be activelly supported

# Translated modules

Currently the next modules translated:

- Call of Cthulhu - Starter set (Paid module)
- Call of Cthulhu - Core Content (Paid module)
